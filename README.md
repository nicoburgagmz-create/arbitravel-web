# Arbi Travel — sitio web

Web de María Iglesias, agente de viajes independiente (Arbi Travel).

## Páginas

- `index.html` — web principal (versión editorial)
- `edicion-poster.html` — segunda propuesta de diseño (misma web, otra paleta/distribución). Marcada `noindex` para no competir en buscadores con `index.html`.
- `politica-privacidad.html` — Política de Privacidad
- `aviso-legal.html` — Aviso Legal

## Publicar con GitHub Pages

1. En GitHub, ve a **Settings → Pages** de este repositorio.
2. En "Source", elige la rama `main` y la carpeta `/ (root)`.
3. Guarda. GitHub te dará una URL del tipo `https://<usuario>.github.io/<repo>/`.
4. Pásame esa URL y actualizo los metadatos SEO (`canonical`, `og:url`) de cada página para que apunten ahí.

## Notas

- Todas las imágenes están incrustadas directamente en el HTML (no hay carpeta de assets aparte).
- Los enlaces entre páginas (footer, navegación) son relativos, así que funcionan en cualquier dominio donde se publique este repositorio.
